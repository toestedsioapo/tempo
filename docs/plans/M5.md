## Review Focus

Inputs and conditions the spec implies but no QG/DOC row names; each has a test in the owning task.

1. **Stryker on a path with spaces and on Windows** (`GitHub Master Plan`, `.stryker-tmp` sandbox copy, A-41 saw plugin auto-discovery fail under pnpm). The first mutation run must succeed on the owner's machine, not only on CI (Task 2).
2. **Non-reproducible survivors:** property tests use random seeds, so a mutant can be killed in one run and survive in the next. Two consecutive runs must report the same survivor set, or the flaky ones are listed and pinned by a fixed example (Task 3).
3. **Fixture hashes and CRLF:** a Windows checkout with `autocrlf` would change every hash. The lock hashes bytes, rejects `\r`, and `.gitattributes` already forces LF for `*.json` (Task 4).
4. **The secret scanner flagging itself** or a fixture/test string that looks like a token; and `.stryker-tmp/` or `reports/` output (git-ignored) being scanned or committed by accident (Task 5).
5. **Docs claiming a thing that does not exist** — the fixtures export above is the known case; the signed-off checklist must name a command or file for every claim, not "looks right" (Task 6).
