# Milestone 1 — Clean restart and foundation: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A green, empty-of-engine-logic, correctly configured pnpm monorepo: the old pre-approval code gone, strict TypeScript toolchain, Zod schemas and types written test-first, a generated `schema/rules.schema.json`, an npm name gate, changesets, and CI on ubuntu + windows × Node 24 + 26.

**Architecture:** Root workspace holds shared tooling and repo-level checks (`tests/`). `@marvinliem/tempo-core` holds Zod schemas (source of truth), inferred types, an `INVALID_INPUT` mapper and a dev-only JSON Schema generator; no engine logic. `@marvinliem/tempo` holds only the exit-code mapping for now. Everything is cross-platform (no bash-only scripts).

**Tech Stack:** TypeScript `~6.0.3`, pnpm `12.15.0`, Node `>=24`, Zod `^4.6.7`, Luxon `^3.7.2`, Vitest `^5.0.5`, ESLint `^10` + typescript-eslint `^8.72`, Ajv (dev only), tsx (dev only), rimraf, changesets, GitHub Actions.

**Spec:** `ROADMAP.md` §M1; `SPEC.md` §3 (types), §3.4 (errors), §4.1 (validation order), §5 (exit codes); `TEST_PLAN.md` §3 (CORE-01 … 07, 40, 41, 42), §9.2 (CFG-01 … 11); `DECISIONS.md` A1/A2 (amended by G29), G23, G24; `ASSUMPTIONS.md` A-19 … A-22, A-24, A-28 … A-30.

## Global Constraints

- `packageManager` is `pnpm@12.15.x`; `engines.node` is `>=24`; `.npmrc` keeps `engine-strict=true`. (G29)
- `pnpm-workspace.yaml`: `packages: ['packages/*']` only; no `workspaces` field in the root `package.json`; no `@my-workspace/shared-ui`. (A1, A2)
- TypeScript `strict` and `noUncheckedIndexedAccess`; ESM; `module`/`moduleResolution` `NodeNext`; relative imports carry `.js`.
- Core runtime dependencies are exactly `luxon` and `zod`. No `Temporal`. Core is pure: no `Date.now()`, `new Date()`, `process.env`, `fs`, network, randomness, no `throw` for expected failures. (CLAUDE.md)
- Scripts must be cross-platform (author is on Windows PowerShell): no bash-only syntax; `rimraf` for clean.
- Zod schemas are the single source of truth; types are `z.infer`'d; `schema/rules.schema.json` is generated, never hand-edited.
- No production code without a failing test first. No secrets or tokens in the repo. Never publish locally.
- Conventional Commits; end every commit message with the `Co-Authored-By:` trailer for the model that actually authored the commit, exactly as given by the harness attribution at commit time (never a hard-coded model name copied from this plan).
- Package names `@marvinliem/tempo-core` and `@marvinliem/tempo`, both `0.1.0`, binary `tempo` (declared in M3, see A-35).
- `--passWithNoTests` never goes through pnpm; M1 has real tests, so it is not used at all.

## Review Focus

Inputs the spec implies but TEST_PLAN's M1 rows do not exercise; each has a test in the named task.

1. **Unknown keys** (`timezone` instead of `timeZone`, a stray top-level key): rejected, path names the offending object, never silently ignored. → Task 4.
2. **Non-object or hostile top-level values** (`null`, `[]`, `"x"`, `42`, JSON with `__proto__`): `INVALID_INPUT` at path `$`, never a throw. → Task 6.
3. **Calendar edges:** `2024-02-29` accepted, `2025-02-29` rejected. → Task 2.
4. **Near-miss formats:** padded `" 09:00"`, `"09:00:00"`, fractional-second or offset `now`. → Tasks 2 and 4.
5. **Windows line endings:** `pnpm gen:schema` on Windows must write LF so the committed file never drifts (CORE-41 compares raw bytes). → Task 8.

**Files:**
