# Tempo — ASSUMPTIONS.md

Every choice not fixed by `DECISIONS.md` (or by an explicit instruction) is recorded here, per `CLAUDE.md` (“Flag every assumption”). Nothing here is silent. **Needs approval** marks the ones I would like you to confirm or veto before implementation starts; the rest are low-risk defaults you can challenge at any time.

`CLAUDE.md` names this file `docs/ASSUMPTIONS.md`; the planning docs currently live at the repo root, so it sits at the root too (see A-19).
