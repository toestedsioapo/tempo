# Tempo — ASSUMPTIONS.md

Every choice not fixed by `DECISIONS.md` (or by an explicit instruction) is recorded here, per `CLAUDE.md` (“Flag every assumption”). Nothing here is silent. Statuses: **approved (Gnn)** = confirmed in round 3 and recorded in `DECISIONS.md`; **default** = a low-risk choice you can challenge at any time; **superseded** = replaced by a later decision. As of round 3 no row is waiting for approval; new assumptions made while implementing are added here and flagged in the PR.

`CLAUDE.md` names this file `docs/ASSUMPTIONS.md`; the planning docs currently live at the repo root, so it sits at the root too (see A-19).
